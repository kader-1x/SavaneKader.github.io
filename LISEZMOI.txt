PORTFOLIO BTS SIO SISR
======================
Ouvrir : double-clic sur index.html (internet requis pour GSAP et les polices).

MODIFIER LE CONTENU
  Tout est dans content.js (identité, parcours, projets, veille).

AJOUTER UN PROJET SANS TOUCHER AU CODE
  1. Ouvrez le site avec #admin à la fin de l’adresse (ex. .../index.html#admin)
  2. Remplissez le formulaire, cliquez sur « Ajouter »
  3. Cliquez sur « Télécharger content.js » et remplacez l’ancien fichier
  4. Envoyez-le sur GitHub : le projet est en ligne pour tout le monde

METTRE EN LIGNE (gratuit) : dépôt GitHub > Settings > Pages > branche main.
IMAGES : mettez-les dans un dossier images/ et indiquez images/nom.png dans le formulaire.
